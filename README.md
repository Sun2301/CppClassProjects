# CppClassProjects

This is a collection of small C/C++ projects and exercises from my C++ class.

Folders:
- `practice/`  — a class exercise (point example)
- `pro1/`       — a C project
- `pro1_Cpp/`   — a C++ project (an employees management system)
- `test1/`      — assorted tests

Quick build (Windows, MinGW/g++):
```
g++ -std=c++17 -Wall practice\pointPlan.cpp practice\point2.cpp -o practice\pointPlan.exe
practice\pointPlan.exe
```

How to add a project: create a new folder, add sources, and include a `README.md` with build/run notes.
